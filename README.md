# Три Імперії — онлайн RTS для 2–3 гравців

Стратегія в реальному часі. Один гравець створює кімнату, друзі заходять
за кодом зі своїх телефонів через одне посилання і грають разом.

Усе намальовано на Canvas простими фігурами. Бекенд — Node.js + Socket.IO.

## Файли
- `index.html` — сторінка гри
- `style.css` — оформлення
- `client.js` — логіка клієнта і малювання
- `server.js` — сервер (синхронізує стан між гравцями)
- `package.json` — залежності

---

## Як грати
1. Один гравець тисне **«Створити кімнату»** → з'явиться код (напр. `ABC123`).
2. Друзі вводять цей код і тиснуть **«Приєднатися»**.
3. Коли всі в лобі — господар тисне **«Почати гру»** (мінімум 2 гравці).
4. Мета — знищити ворожі бази. Остання імперія перемагає.

**Керування (палець):**
- Тап по клітинці — вибір бази/юнітів або наказ руху обраному війську.
- Перетягування — рухає камеру.
- **Армія** — вибрати всіх своїх юнітів.
- **Створити** → Солдат / Лучник / Танк (з обраної бази чи казарми).
- **Будувати** → Шахта / Казарма / Вежа, далі тап по своїй клітинці.
- **Атака** — наступний тап відправить військо в атаку на ціль.

Юніти: Солдат (швидкий), Лучник (б'є здалеку), Танк (сильний, повільний).
Будівлі: База, Шахта (+ресурси), Казарма (робить військо), Вежа (сама стріляє).

## Запуск БЕЗ комп'ютера (тільки з телефона)

Найпростіший безкоштовний шлях — **GitHub + Render**. Усе робиться в браузері телефона.

### Крок 1. Завантаж файли на телефон
Збережи ці 5 файлів собі в телефон (вони вже є в цьому наборі):
`index.html`, `style.css`, `client.js`, `server.js`, `package.json`.

### Крок 2. Створи репозиторій на GitHub
1. Зайди на **github.com**, зареєструйся (безкоштовно).
2. Тисни **+** (вгорі) → **New repository**.
3. Назви його, напр. `three-empires`, зроби **Public**, тисни **Create repository**.
4. На сторінці репозиторію: **Add file → Upload files**.
5. Обери всі 5 файлів з телефона, тисни **Commit changes**.

> Важливо: файли мають лежати в корені репозиторію (не в підпапці).

### Крок 3. Задеплой на Render (безкоштовно)
1. Зайди на **render.com**, увійди через **GitHub**.
2. **New + → Web Service** → обери свій репозиторій `three-empires`.
3. Заповни:
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Instance Type**: **Free**
4. Тисни **Create Web Service** і зачекай 1–2 хвилини (перший запуск).
5. Угорі з'явиться адреса типу **`https://three-empires-xxxx.onrender.com`**.

### Крок 4. Грайте
- Це посилання — і є ваша гра. Кинь його друзям у чат.
- Кожен відкриває його на своєму телефоні.
- Один тисне «Створити кімнату», решта вводять код. Господар — «Почати гру».

> На безкоштовному Render сервер «засинає» після ~15 хв без гравців.
> Тоді перше відкриття посилання триває ~30–60 сек (сервер прокидається) — це нормально.

## Альтернатива: Glitch (ще простіше, але менш стабільно)
1. Зайди на **glitch.com**, увійди.
2. **New project → Import from GitHub** → встав посилання на свій GitHub-репозиторій.
3. Glitch сам запустить сервер. Тисни **Share → Live site** — це і є посилання для друзів.

---

## Якщо колись буде комп'ютер (локальний запуск)
```bash
npm install
npm start
```
Відкрий `http://localhost:3000`. Щоб зайти з телефонів у тій самій Wi-Fi мережі —
використай локальну IP-адресу ПК, напр. `http://192.168.1.5:3000`.

## Перевірити гру самому (без друзів)
Відкрий посилання у 2–3 вкладках браузера. В одній створи кімнату,
в інших приєднайся за кодом — так можна протестувати мультиплеєр наодинці.

## ⚠️ Оновлення до v4 — важливо про папку assets

У v4 додано спрайти червоної команди. Щоб вони показувались, на GitHub має зʼявитися папка **`assets`** з 18 файлами `.png`.

**Що завантажити на GitHub (заміна/додавання):**
1. `server.js`, `client.js`, `index.html`, `style.css`, `package.json` — замінити (Add file → Upload files → Commit).
2. **Папку `assets`** — завантажити цілком. На телефоні найпростіше: `Add file → Upload files`, а тоді перетягнути/вибрати **всі 18 файлів** із папки `assets`, і у полі імені перед файлами не обовʼязково писати `assets/` — GitHub створить папку сам, якщо завантажувати через «Upload» і додати шлях. Якщо не виходить створити папку з телефона — напиши мені, підкажу альтернативу (можна залити архів або створювати файли вручну через `Create new file` з іменем `assets/red_guild.png` — але для картинок краще Upload).

Якщо папки `assets` не буде — гра все одно працює, але червона команда малюватиметься простими фігурами (як інші кольори), без картинок.

Render перезбереться автоматично після коміту (30–90 с).
